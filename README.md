# LeetCode Solutions

This repository contains my personal solutions to various [LeetCode](https://leetcode.com/) problems, implemented across multiple programming languages.

## Project Structure

The solutions are organized first by language, and then by difficulty level (`easy`, `medium`, `hard`).

```text
.
├── go/
│   └── medium/
├── java/
│   ├── easy/
│   ├── hard/
│   └── medium/
├── python/
│   ├── easy/
│   ├── hard/
│   └── medium/
└── typeScript/
    ├── easy/
    ├── hard/
    └── medium/
```

## Languages & Tech Stack

Currently, the repository includes solutions in the following languages:

- **Java**
- **Python**
- **Go**
- **TypeScript**

*Note: For TypeScript solutions, a `tsconfig.json` is provided which compiles the code to ES5/CommonJS.*

## File Naming Convention

Files are typically named following a convention that includes the problem name and its LeetCode ID.
Example: `BestTimeToBuyAndSellStock_121.java` or `best_sihtseein_pair_1014.py`.
